# Auditory fuzzy-model development comparison

This analysis compares two independent fuzzy approximations of the existing Auditory difficulty regression: the tree-derived Mamdani approach (3 and 5 output terms reported separately) and the three-cluster, constant-output Sugeno approach. It does not retrain the original regression or select a final fuzzy method.

## Data and evaluation

All results concern the 26 development participants and their four Auditory sessions each (104 observations). The script first verifies the original regression predictions and the saved modelling sources. For the Sugeno method, it repeats 26 rounds: fit scaling, three fuzzy clusters and three output constants on 25 participants, then predict the remaining participant's four sessions. Mamdani's corresponding participant-excluded predictions have already been generated by its own evaluation script and are read rather than recomputed.

The output reports the training results alongside participant-excluded results. Because the original regression was trained using all 26 development participants, the participant-excluded comparison only tests how well the fuzzy methods reproduce that existing regression for participants left out of *fuzzy-model* fitting. It does not independently measure the accuracy of the original regression.

For each method, two references are reported separately: the observed difficulty stage (0, 1, 2 or 3) and the numerical output of the original regression. The metrics are:
- MAE: the average absolute difference, calculated per participant before averaging participants;
- R²: pooled across eligible observations, using the reference values as the comparison;
- Accuracy: percentages within 0.25, 0.50 and 0.75 **difficulty-stage units**, counting a prediction only when its absolute error is strictly **less** than the threshold. No rounding, clipping or multiplying by the full target range.

The accuracy definition matches the existing accuracy-sensitivity extension. It is not exact-level classification accuracy.

Mamdani may mark a prediction **Unavailable**. Such observations are not replaced with invented values. Each metric states how many observations were available, so results based on different coverage are not treated as directly equivalent.

## Run locally (PowerShell)

First run the focused tests:

```powershell
python -m unittest discover -s tests -p "test_MOD_19_auditory_fuzzy_metrics.py" -v
```

Then identify the existing Mamdani output directories containing `output_term_predictions.csv` and `grouped_predictions.csv`, respectively, and run:

```powershell
python python/MOD_19_auditory_fuzzy_metrics.py `
  --modeling-data "outputs/modeling/modeling_data.csv" `
  --holdout-split "<verified path to participant_holdout_split.csv>" `
  --mod14-output-dir "outputs/MOD_14_direct_linear_regression_evaluation" `
  --fcm-stage1-dir "outputs/MOD_19_auditory_fcm_stage1_k3" `
  --sugeno-training-dir "outputs/MOD_19_auditory_fcm_stage2b_k3" `
  --mamdani-training-dir "<verified Mamdani output-term directory>" `
  --mamdani-grouped-dir "<verified Mamdani grouped-validation directory>" `
  --output-dir "outputs/MOD_19_auditory_fuzzy_metrics_development"
```

The output directory must not exist before execution. The three files created locally are `development_metrics.csv`, `sugeno_grouped_predictions.csv` and `sugeno_fold_diagnostics.csv`, together with `comparison_manifest.json` documenting provenance and limits. Participant-level output remains local and is not added to GitHub.

## Limits and subsequent stages

The three-cluster configuration and fuzzifier were set provisionally before this check. The comparison is developmental evidence, not a final model decision. No reserved-test participants are used. Only after the methods and reporting procedure are finalised should the separate six-participant final evaluation be performed, without adjusting models in response to its results.

Therapist-interface design is another stage. The existing research plan distinguishes SHAP explanations of an individual regression prediction from the fuzzy-rule explanation/adaptation approach. Evaluating Mamdani against Sugeno does not replace that SHAP-versus-fuzzy design question. Clinical decisions remain the therapist's responsibility.
